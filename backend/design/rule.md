# 后端编码约定

已确认：Node.js + TypeScript + NestJS 12（Fastify 适配器）+ `@nestjs/swagger`；Better Auth 管会话；CASL 做权限判定；PostgreSQL + Prisma 7 为存储。

## 分层与边界

- 接口层负责协议适配和输入输出，不承载复杂业务流程。
- 业务规则与基础设施细节分离；存储、消息和外部服务通过明确边界接入。
- 跨层数据契约保持稳定、简单、可验证，避免把内部实现直接暴露给调用方。
- 输入在系统边界校验；权限校验默认在可信服务端执行。
- 登录与会话由 Better Auth 处理，不要把前端持有的令牌当作权限真相。
- CASL 只负责判定；Nest Guard 负责拒绝未登录和无权限请求。列表查询必须带角色或归属条件，禁止只在内存里丢弃结果。
- 数据访问通过明确边界接入 PostgreSQL，不把存储细节泄漏到接口层。课时、冲突等不变量还要落在数据库约束和事务里。

## 抽象与错误处理

- 保持高内聚、低耦合，不创建只改名并透传参数的包装层。
- 仅在承载规则、隔离变化、统一副作用或明显减少重复时新增抽象。
- 错误应保留可诊断上下文，对外信息不得泄露密钥、内部路径或敏感数据。
- 超时、重试、幂等性和事务边界按实际风险设计，不默认无限重试或静默吞错。

## 实现与验证

- 命名表达领域含义；避免魔法值、隐式全局状态和职责混杂的超长函数。
- 配置与代码分离，敏感配置只从受控环境读取。
- 测试覆盖核心规则、失败路径和边界条件；外部系统使用可控替身或独立集成测试。
- 格式化、静态检查和测试以仓库已有配置为准；尚未配置时不擅自引入工具。
